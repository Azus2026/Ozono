# Ozono Labs - Generador de Ozono HS-Y01

Landing page 3D interactiva para el sistema de esterilización y purificación industrial HS-Y01.

## Características
- **Experiencia 3D por Scroll:** Secuencia de 124 fotogramas en WebP de alta definición y carga progresiva.
- **Pasarela Cripto Web3:** Integración con billeteras Web3 (MetaMask, Coinbase Wallet, etc.) en **Arbitrum One** y **Base Network** con USDC.
- **Pasarela de Tarjetas Perú:** Integración con **Mercado Pago Perú** (Visa, Mastercard, Amex, Diners, débito y crédito) y transferencias directas con Yape / Plin.
- **Atención al Cliente:** Enlaces y cotizaciones automatizadas directo a WhatsApp (+51 923 541 297).
- **Despliegue Optimizado:** Configurado para **Vercel** con caché inmutable en CDN global para los fotogramas 3D.
